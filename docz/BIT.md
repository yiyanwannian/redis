# Fenwick树（二叉索引树）详解

---

## 一、概述

**Fenwick树**（又称二叉索引树，Binary Indexed Tree，BIT）是一种高效维护动态前缀和的数据结构，由Peter Fenwick于1994年提出。其核心思想是通过 **二进制索引的位运算特性**，在 **O(log n)** 时间复杂度内支持 **单点更新** 和 **前缀查询**，适用于高频更新与快速查询并存的场景。

### 1.1 设计动机
- **传统方法的缺陷**：
  - 普通数组：查询O(n)，更新O(1) → 查询效率低
  - 前缀和数组：查询O(1)，更新O(n) → 更新效率低
  - 线段树：查询和更新均为O(log n)，但实现复杂且空间开销大
- **核心需求**：  
  在动态数据场景中（如实时数据流），需平衡 **更新效率** 与 **查询效率**。

### 1.2 核心优势
- **时间复杂度**：  
  - 单点更新：O(log n)  
  - 前缀查询：O(log n)  
- **空间复杂度**：O(n)  
- **实现简洁**：仅需10-20行代码，无需递归或复杂指针操作。

---

## 二、核心设计原理

### 2.1 二进制索引与LSB（最低有效位）
- **二进制索引**：每个整数可唯一表示为2的幂次之和（如 `7 = 4 + 2 + 1`）。
- **LSB定义**：

  \[
  \text{LSB}(i) = i \ \& \ -i \quad (\text{保留二进制中最右侧的1})
  \]

  - 示例：  
    - `LSB(6) = 2`（`6 = 110_2` → 最右侧的1对应`2^1=2`）  
    - `LSB(4) = 4`（`4 = 100_2` → 最右侧的1对应`2^2=4`）

### 2.2 区间管理规则
- **管理区间**：  
  索引 `i` 管理的区间为 `[i - LSB(i) + 1, i]`，长度为 `LSB(i)`。
- **覆盖示例**：

  | 索引 `i` | 二进制    | LSB | 管理区间  | 覆盖元素    |
  |--------|--------|-----|-------|---------|
  | 6      | `110`  | 2   | [5,6] | 第5、6个元素 |
  | 4      | `100`  | 4   | [1,4] | 第1-4个元素 |
  | 8      | `1000` | 8   | [1,8] | 所有元素    |

### 2.3 树状层级结构
- **节点职责**：  
  `tree[i]` 存储其管理区间的部分和。
- **跳跃规则**：
  - **查询**：从 `i` 开始，不断减去 `LSB(i)` 向上跳跃，累加路径值。
  - **更新**：从 `i` 开始，不断加上 `LSB(i)` 向下传播，更新父节点。

---

## 三、操作实现

### 3.1 查询操作（前缀和）
**目标**：计算前 `i` 个元素的和。  
**步骤**：
1. 初始化 `sum = 0`。
2. 循环执行以下操作，直到 `i = 0`：
   - `sum += tree[i]`
   - `i -= LSB(i)`（向上跳跃）
3. 返回 `sum`。

**伪代码**：
```python
def query(i):
    sum = 0
    while i > 0:
        sum += tree[i]
        i -= i & -i  # 减去LSB
    return sum
```

**时间复杂度**：O(log n)

---

### 3.2 更新操作（单点修改）
**目标**：将第 `i` 个元素的值增加 `delta`。  
**步骤**：
1. 循环执行以下操作，直到 `i > n`：
   - `tree[i] += delta`
   - `i += LSB(i)`（向下传播）
   
**伪代码**：
```python
def update(i, delta):
    while i <= n:
        tree[i] += delta
        i += i & -i  # 加上LSB
```

**时间复杂度**：O(log n)

## 四、应用场景

### 4.1 逆序对统计
- **问题描述**：统计数组中满足 `i < j` 且 `a[i] > a[j]` 的逆序对数量。
- **解决方案**：  
  1. 离散化数组值到排名。  
  2. 从右向左遍历，用Fenwick树统计右侧已处理元素中排名小于当前元素的个数。

### 4.2 动态频率统计
- **问题描述**：实时统计某值域范围内元素的出现次数（如统计等级在[10,20]的玩家数量）。
- **解决方案**：  
  维护频率数组的Fenwick树，通过前缀和差值计算区间频率。

### 4.3 多维扩展
- **二维Fenwick树**：  
  用于图像处理或矩阵中矩形区域和的查询（时间复杂度O(log m log n)）。

## 五、示例演示

### 5.1 示例1：数组 `[1,2,3,4,5,6,7,8]`
**Fenwick树结构**：

| 索引 | 1 | 2 | 3 | 4  | 5 | 6  | 7 | 8  |
|----|---|---|---|----|---|----|---|----|
| 值  | 1 | 3 | 3 | 10 | 5 | 11 | 7 | 36 |

**查询前7个元素的和**：
1. **步骤1**：访问 `tree[7]`（值7 → 覆盖元素7） → `sum=7`  
2. **步骤2**：访问 `tree[6]`（值11 → 覆盖元素5,6） → `sum=18`  
3. **步骤3**：访问 `tree[4]`（值10 → 覆盖元素1-4） → `sum=28`  
**结果**：`1+2+3+4+5+6+7=28`，与计算一致。

### 5.2 示例2：数组 `[3,1,4,2]` 的逆序对统计
1. **离散化**：数组值映射为排名 `[3→3, 1→1, 4→4, 2→2]`。
2. **从右向左处理**：
   - 元素2（排名2）：查询前1名的数量 → 0 → 逆序对数+0  
   - 元素4（排名4）：查询前3名的数量 → 3 → 逆序对数+3  
   - 元素1（排名1）：查询前0名的数量 → 0 → 逆序对数+0  
   - 元素3（排名3）：查询前2名的数量 → 2 → 逆序对数+2  
**总计**：3+2=5（实际逆序对为 (3,1), (3,2), (4,2), (4,1), (3,1) → 需去重）。

## 六、扩展与变体

### 6.1 0-based索引实现
- **核心调整**：  
  对外接口使用0-based索引，内部转换为1-based逻辑：
  ```python
  class FenwickTree:
      def __init__(self, size):
          self.n = size
          self.tree = [0] * (self.n + 1)  # 内部1-based
      
      def query(self, pos):  # 对外0-based接口
          res = 0
          pos += 1  # 转换为1-based
          while pos > 0:
              res += self.tree[pos]
              pos -= pos & -pos
          return res
  ```

### 6.2 多维Fenwick树
- **二维实现**：  
  嵌套使用一维Fenwick树，支持矩阵区域和查询：
  ```python
  class FenwickTree2D:
      def __init__(self, rows, cols):
          self.rows = rows
          self.cols = cols
          self.tree = [[0]*(cols+1) for _ in range(rows+1)]
      
      def update(self, x, y, delta):
          x += 1; y += 1
          while x <= self.rows:
              y_temp = y
              while y_temp <= self.cols:
                  self.tree[x][y_temp] += delta
                  y_temp += y_temp & -y_temp
              x += x & -x
  ```

## 七、总结

### 7.1 核心优势
- **高效性**：O(log n)的更新与查询，适合动态数据场景。
- **简洁性**：代码实现简单，无需复杂结构。
- **空间优化**：仅需线性额外空间。

### 7.2 适用场景
- 高频单点更新 + 快速前缀查询
- 逆序对统计、动态频率分析、多维区域和查询

### 7.3 限制
- **功能局限**：仅支持前缀和或频率统计，无法直接处理最值等操作。
- **维度扩展**：多维实现复杂度较高。
